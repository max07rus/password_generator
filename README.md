# Random Password Generator

**Автор:** Антропов Максим Сергеевич

## Описание
GUI-приложение для генерации случайных паролей с настройкой параметров и сохранением истории в формате JSON.
Проект выполнен на языке Python с использованием графической библиотеки `tkinter`.

## Возможности
- Ползунок длины пароля (допустимый диапазон: 4–64 символа).
- Выбор типов символов:
  - цифры (0–9),
  - буквы латинского алфавита (a–z, A–Z),
  - спецсимволы (!@#$%^&*()_+-=[]{}|;:,.<>?).
- Кнопка генерации пароля.
- Отображение результата в поле и возможность копирования в буфер обмена.
- Таблица истории генераций.
- Сохранение и загрузка истории из JSON-файла.

## Требования
- Python ≥ 3.10.

## Запуск
1. Откройте терминал в папке проекта.
2. Запустите приложение:
   ```bash
   python main.py
   ```

## Примеры использования (входные параметры)
- Длина: 12, все типы символов включены.
- Длина: 8, только буквы и цифры.
- Длина: 16, только буквы.

## Хранение истории
История генераций автоматически сохраняется в файл `history.json` и загружается при запуске приложения.
Файл создаётся при первой генерации, если отсутствует.
